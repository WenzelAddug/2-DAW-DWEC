# 2-DAW-DWEC

Ejercicios del módulo **Desarrollo Web en Entorno Cliente (DWEC)** de 2º de DAW, curso 2026-2027.

Todo está hecho con HTML y JavaScript sin librerías, con el script dentro de cada página.

## Contenido

| Carpeta | Qué hay |
| --- | --- |
| [Calculadora](./Calculadora) | Calculadora con botones y teclado |
| [Dado](./Dado) | Simulación del lanzamiento de un dado |
| [Imagenes](./Imagenes) | Carrusel que va pasando imágenes |
| [EjerciciosBateria](./EjerciciosBateria) | Batería de ejercicios de cadenas, arrays y números aleatorios |
| [Ejercicios con Cruzado(en clase)](./Ejercicios%20con%20Cruzado(en%20clase)) | Ejercicios hechos en clase: formularios, condicionales y bucles |

Cada carpeta tiene su propio README con el detalle de los ejercicios.

## Cómo probarlo

No hay que instalar nada. Clona el repositorio y abre cualquier archivo `.html` en el navegador:

```bash
git clone https://github.com/WenzelAddug/2-DAW-DWEC.git
```

Algunos ejercicios escriben el resultado en la consola, así que conviene tener abiertas las herramientas de desarrollo (F12).
